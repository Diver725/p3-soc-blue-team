# P3 环境设计与第 1 周计划

## 一、P3 定位

P3 是企业 SOC 安全运营与蓝队应急响应演练。

目标能力：

```text
SIEM 日志集中
告警研判
IOC 提取
攻击链还原
应急处置
主机隔离
复测和复盘
蓝队值守记录
态势感知仪表盘
```

与 P2 的关系：

```text
P2 负责发现和修复漏洞
P3 负责持续监控、发现攻击、研判和响应
```

## 二、推荐实验网络

当前已有 Host-only：

```text
#2：192.168.10.0/24
#3：192.168.20.0/24
```

P3 新建独立 Host-only：

```text
#4：192.168.30.0/24
Windows 主机：192.168.30.1
```

不要让 P3 复用 P1/P2 的网段，避免历史规则、告警和资产混淆。

## 三、P3 主机规划

| 主机 | IP | 角色 | 内存 |
|---|---|---|---:|
| p3-wazuh | 192.168.30.10 | Wazuh Manager / Indexer / Dashboard | 8GB |
| p3-dvwa | 192.168.30.20 | Web 靶机、DVWA、Agent | 2GB |
| p3-kali | 192.168.30.30 | 攻击机，仅内网 | 2GB |
| Windows 主机 | 192.168.30.1 | 管理入口，可选访问 Dashboard | - |

每台虚拟机建议：

```text
网卡 1：Host-only #4，静态 IP
网卡 2：NAT，用于安装软件和访问更新源
```

## 四、建设顺序

### 第 1 周：SOC 基础环境

1. 创建 Host-only #4。
2. 基于现有安全 Ubuntu 模板创建：
   - p3-wazuh
   - p3-dvwa
3. 配置静态 IP：
   - `192.168.30.10`
   - `192.168.30.20`
4. 确认三台机器 SSH 管理。
5. 安装 Wazuh 单节点：
   - Wazuh Manager
   - Wazuh Indexer
   - Wazuh Dashboard
6. 部署 DVWA：
   - Apache
   - PHP
   - MariaDB
   - DVWA
7. 在 DVWA 安装 Wazuh Agent。
8. 采集认证日志、Web 日志、系统日志。
9. 验证 Dashboard 能看到日志和 Agent。

### 第 2-3 周：检测和事件模拟

计划模拟：

```text
SSH 暴力破解
Web SQL 注入
Web 目录扫描
可疑文件创建或修改
sudo/提权异常
```

每次模拟都要：

```text
说明攻击目标
保留原始日志
查看 Wazuh 告警
判断规则是否准确
提取 IOC
进行处置
复测确认
```

### 第 4-5 周：分析员工作流

```text
告警接收
→ 初步研判
→ 证据收集
→ 影响范围判断
→ IOC 提取
→ 处置动作
→ 恢复验证
→ 事件报告
```

### 第 6 周：态势和收尾

- Dashboard 视图
- 告警趋势
- 高频源 IP
- 事件报告归档
- 项目总结和面试材料

## 五、内存和运行策略

建议 P3 运行时不要同时运行 P1/P2 全套环境。

典型 P3 组合：

```text
p3-wazuh 8GB
p3-dvwa 2GB
p3-kali 2GB
合计 12GB
```

主机 24GB，可以保留约 12GB 给 Windows 和日常软件。

## 六、基础工具

Wazuh 负责：

```text
日志采集
规则匹配
告警生成
资产管理
安全事件展示
```

DVWA 负责：

```text
提供可控 Web 攻击目标
产生 Web 访问、SQL、文件上传等日志
```

Kali 负责：

```text
在 host-only 隔离网络中生成攻击流量
```

## 七、第 1 周第一步

建议从创建 Host-only #4 开始：

```text
网络名：P3 Host-Only
网段：192.168.30.0/24
主机地址：192.168.30.1
DHCP：Disabled
```

然后决定基础 VM：

- 优先使用 D 盘上的 Ubuntu 安全模板或现有安全 Ubuntu 克隆。
- 不直接把 P3 建立在容易掉线的 E 盘外置 SSD 上。
- 创建虚拟机后先打基础快照。

## 八、P3 安全红线

```text
只扫描和攻击 host-only 内实验靶机
不使用真实恶意软件
所有事件模拟先通知自己并留档
不扫描公网
不把 Wazuh Dashboard 暴露到公网
```

## 九、第一周交付物

- P3 网络拓扑
- 主机和 IP 台账
- Wazuh 单节点运行
- DVWA 可访问
- Agent 在线
- 能看到日志进入 Dashboard
- 第 1 周部署记录
