# P3 理论补课与复现手册

> 目的：在第一轮 P3 流程完成后，补齐环境架构、Wazuh、日志解析、告警研判和应急响应的理论基础。
>
> 学习方式：先理解，再观察现有环境，最后做半扶和独立复现。

## 一、学习路线

| 模块 | 主题 | 重点 |
|---|---|---|
| M1 | P3 环境与架构 | 三台主机、Host-only/NAT、组件分工 |
| M2 | Wazuh 架构与日志流 | Agent、Manager、Indexer、Dashboard |
| M3 | 日志解析与规则 | Predecoder、Decoder、Rule、告警字段 |
| M4 | 告警研判与 IOC | True/False Positive、证据、攻击来源、范围 |
| M5 | 应急处置 | 阻断、隔离、恢复、复测 |
| M6 | 安全事件报告 | 时间线、IOC、影响、处置和复盘 |
| M7 | Dashboard 与值守 | 告警趋势、资产、规则和运营指标 |

## 二、环境搭建需要掌握什么

需要理解：

```text
三台主机各自负责什么
Host-only 用于实验通信
NAT 用于联网安装
Wazuh Agent 为什么装在靶机
为什么实验必须隔离
快照和恢复为什么重要
```

不需要死记：

```text
Wazuh 安装脚本的完整命令
所有 apt 包列表
所有 netplan/nmcli 参数
Web 和数据库安装过程中的每一个细节
```
